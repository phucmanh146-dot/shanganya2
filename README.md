# 🍔 麦麦搭子 · 省着吃 / Maiai Buddy

> 通勤 × 投票 × 奶奶家：让预算有限的下班搭子少纠结一会儿，一起决定今晚吃什么。

## 项目介绍
这是独立原创创意原型，针对下班途中想吃麦当劳但又想合理控制预算的人群，提供预算记录、口味选择、候选方案投票和结果展示。采用奶油粉、复古菜单牌与阿婆的小纸条的手账视觉风格，支持移动端。

## 已实现
- 浏览器打开 `index.html` 即可体验响应式交互页面。
- 输入预算、人数、口味；选择三个主题方向投票。
- 展示本地投票比例、领先结果及邀请文案。
- `mcp-client.mjs` 提供 Node.js 20+ MCP 初始化和 `tools/list` 动态发现脚本。

## MCP 测试
1. 在麦当劳开放平台申请并安全保管 Token；不要把凭据上传 GitHub。
2. 本机环境变量 `MCD_MCP_TOKEN` 填入有效 Token，运行 `node mcp-client.mjs`。
3. 通过 `tools/list` 获取服务端的真实工具名和参数，不虚构优惠接口。
4. 参考 [MCP_INTEGRATION.md](MCP_INTEGRATION.md) 进行接入与排错。
